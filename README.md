## Publish with GitHub Pages
1. Create or choose a GitHub repository.
2. Upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.
5. GitHub will provide your public Pages URL.
6. Generate the final QR code using that public URL.
